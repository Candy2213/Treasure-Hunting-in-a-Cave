# Treasure Hunting in a Cave

A small Unity 3D exploration and collection game developed with C#.

## Features

* Opening cinematic created with Timeline and Cinemachine
* Third-person character control
* Cave exploration environment
* Coin collection system
* Terrain and cave built using ProBuilder

## Development Tools

* Unity
* C#
* Cinemachine
* Timeline
* ProBuilder

## Gameplay

The player starts outside a cave, watches a short opening sequence, enters the cave, and collects coins to complete the objective.
